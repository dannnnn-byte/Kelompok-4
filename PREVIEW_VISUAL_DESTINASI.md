## 🎯 User Journey

```
1. User di halaman paket wisata (wisatamalang.php)
   ↓
2. Scroll ke section "Galeri Destinasi"
   ↓
3. Lihat card destinasi dengan foto + nama + deskripsi singkat
   ↓
4. Klik tombol "Overview ➜"
   ↓
5. Buka halaman detail destinasi (destinasi_detail.php?id=X)
   ↓
6. Lihat informasi lengkap:
   - Hero section dengan nama besar
   - Gallery 3 foto
   - Info card jam, harga, kontak, website
   - Deskripsi lengkap
   - Fasilitas lengkap
   - Tips kunjungan
   ↓
7. Klik "Kembali ke Paket Wisata"
   ↓
8. Kembali ke halaman paket
```
